# ACA's Creative QA Checklist

⛔ **Emit every row below, marked.** Not a summary of what was checked.

**Two halves, and a separate pass for image ads.** Every row is scored **Good to Go** or **Needs
attention** in ACA's original, plus `Cannot assess` and `N/A` for the honest cases ACA does not
provide for.

---

# Part 1: Technical Review

## Format & Specifications

| Row |
|---|
| **Asset length appropriate for platform and concept** |
| **Correct aspect ratios delivered for each platform** |
| **Safe zones respected** — no key elements in areas covered by UI elements |

### ⭐ ACA's runtime bands

| Platform | Length |
|---|---|
| **TikTok** | **7-40 seconds** |
| **Meta** | **15-45 seconds** |
| **YouTube** | **20-45 seconds** |

> "**Only VSL ads can be longer than 1 minute.**"

### The aspect ratios

| Platform | Ratios |
|---|---|
| **Meta** | 9:16, 4:5 and 1:1 |
| **TikTok** | 9:16 |
| **YouTube** | 9:16 and 16:9 |

⛔ **These are ACA's numbers, current as of an undated recording.** Platform specs change. Score
against them, and say in the output that the current platform documentation should be the final
word before delivery.

## Text and Audio Check

| Row |
|---|
| **Zero spelling / grammar errors** |
| **Correct fonts** — brand fonts for branded ads, native fonts for UGC/native formats — **and sized for mobile legibility** |
| **Supers support rather than distract from audio** |
| **Closed captions match spoken words and never cover key visuals** |
| **Clean audio** with no background noise or static |
| **Consistent volume levels throughout** |
| **Music/SFX balanced properly with voice** |
| **Does the music add to the ad, or is it distracting?** |
| ⛔ **No copyright issues with music or sound effects** |
| ⭐ **Does the hook have an audio pattern interrupt / "ear stopper" in the first 3 seconds?** |

⚠️ **The captions row is two tests in one** — accuracy *and* placement. A caption that is word-perfect
and sits over the product fails it.

## Brand Compliance

| Row |
|---|
| **Brand colours, logo, disclaimers used exactly to guidelines** |
| **Tone of voice and visuals matches brand** |
| **Disclaimers included when required** |

⛔ **All three are `Cannot assess` without the brand guidelines.** "Looks on-brand to me" is not a
check against a guideline.

## Creative Integrity Check

| Row |
|---|
| ⭐ **Has anything been missed from the storyboards?** |
| **If there are before and afters, are they clear? Do we CLEARLY see a before and after?** |
| **Does the ad feel authentic and relatable, or does it feel fake?** |
| **Have we added strong testimonials and social proof?** |
| **If the ad is a street interview, is the acting natural?** |
| **If it's a podcast, does the setup and lighting look good / professional / legit?** |
| **Do the screen recordings highlight the key feature, not generic scrolling?** |
| **Props, lighting and setting match the narrative** — e.g. night scenes for sleep products |

⛔ **The first row needs the storyboard.** Without it this whole section is `Cannot assess`, and it
is the section that catches the most expensive class of error: the shot that was briefed, paid for
and never delivered.

⚠️ **Three of these rows are format-conditional** — before/afters, street interview, podcast. Mark
them `N/A` with the reason rather than passing them by default.

# Part 2: Performance Optimization

## Hook Effectiveness (first 3 seconds)

| Row |
|---|
| **Pattern interrupt present?** Movement, strong visual |
| **Does the hook create curiosity or emotion?** |
| **Clear persona represented?** |
| **Problem statement immediate and clear?** |
| **Engaging visual that supports the message?** |
| **Does the sound work as an "ear-stopper"?** |

⭐ **These six are the five elements of a hook, plus the pattern interrupt.** An ad failing three of
them does not need a note on each; it needs a new opener.

## Hook Variation

| Row |
|---|
| **Are the hooks sufficiently different from each other?** |
| **Does each hook test a different visual approach or messaging angle?** |

⛔ **This section needs the rest of the batch.** One asset in isolation cannot be scored on variation
— mark it `Cannot assess` and ask for the siblings.

## Thumbnail Assessment

| Row |
|---|
| **Is the first frame strong?** Is there enough on frame to make the person stop scrolling? |
| **Is the visual interesting? Is there a strong headline?** Combined, what is their effect? |
| **Product or key visual clearly visible?** |
| **Would this stand out in a crowded feed?** |

## Pacing and Structure

| Row |
|---|
| **Quick pacing with no dead spots** |
| ⭐ **Did we use the heartbeat method? Something changes every 1.5 seconds** |
| **Clear story progression** — Hook → Body → CTA |
| **Effective use of pattern interrupts throughout the whole ad** |
| **No unnecessary pauses or filler content** — no longer than 2-3 seconds on the same visual |

⭐ **The heartbeat method is the most checkable row in the whole document**, and it appears nowhere in
the course narration. A change every 1.5 seconds is countable from a timeline, so score it with a
number rather than an impression.

## Call to Action

| Row |
|---|
| **Clear, specific CTA present** |
| **CTA aligns with conversion objective** |
| **Urgency created when appropriate** |
| **Visually distinct from other content** |
| **Reinforces main value proposition** |

⚠️ **Row 2 needs the objective.** A CTA that says "learn more" is right for traffic and wrong for
purchase, and nothing on the asset itself reveals which was bought.

## Final Gut Check

| Row |
|---|
| **Would you stop and watch it end-to-end?** |
| **Do these look good to you? (Be honest)** |
| **Do these ads follow the brief?** |
| **Are you proud to send these for client review?** |

⭐ **ACA put "(Be honest)" in the document itself**, which tells you what usually happens to this
section. It is the only part of the checklist that cannot be gamed by a spec sheet, and a batch that
passes every technical row and fails the gut check is a batch worth stopping.

# The image-ad pass

⚠️ **A separate page in ACA's checklist**, for statics rather than video.

| Row |
|---|
| **Where does your eye go first? Is that the intended effect?** ⭐ *Look at the asset on your phone* |
| **Is it easy to read? Can you cut out any words from the copy?** |
| **Are you using the right visual? Does it compete too much with the messaging?** |
| **Take a look at your inspiration ad** — the reference in the brief. Is it better or worse? |
| **Is the copy strong? Is it VERY clear what problem this product or service solves?** |
| ⛔ **Is this a Branded, Native or Expert ad? Is that CLEAR? It should not be a mix of these** |
| **How can you make your ad better?** |
| **Do these look good to you? (Be honest)** |
| **Do these ads follow the brief?** |
| **Are you proud to send these for client review?** |

⭐ **"Look at the asset on your phone" is a literal instruction and it changes results.** Everything
here is judged at feed size on a handset, not at 100% on a monitor.

⛔ **The Branded / Native / Expert row is the one with teeth.** A static that is half native and half
branded reads as neither, and this is the only row in the whole document that names a failure mode
rather than a quality.

## ⛔ Before delivering it

1. **A count at the top**: how many Good to Go, Needs attention, Cannot assess, N/A
2. ⛔ **The `Cannot assess` rows listed together with what would settle them**, because that list is
   the actual request back to whoever sent the asset
3. **A launch verdict in one line** — and it is `hold` if any Technical row failed, whatever the
   performance half says
   - ⛔ **It is also `hold` if any Technical row is `Cannot assess`.** The verdict keys on coverage,
     not only on failures: a checklist where nothing failed *because nothing could be checked* is
     exactly the certification `Cannot assess` exists to prevent. **Never clear an asset for launch
     off a pass you could not perform** — the honest verdict is `hold, pending <the missing inputs>`
4. ⚠️ **The reminder that ACA asks for at least two human reviewers**, and this pass is one set of
   eyes
5. ⛔ **No row silently dropped.** Every row in the document appears in the output with a mark

⚠️ **Do not soften a Needs attention into a suggestion.** The document exists to stop assets going
live, and a note phrased as an option gets treated as one.
