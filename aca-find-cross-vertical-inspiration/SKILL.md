# Find cross-vertical creative inspiration

Ad Creative Academy's Course 230 artifact, run for a specific brand. This skill runs the research.
It does not teach cross-channel strategy.

> "This prompt helps you **break out of your industry bubble** and discover fresh creative
> approaches that will make your ads stand out while still resonating with your target audience."

**The output is a research plan, not a set of findings.** That distinction is the whole skill; see
below.

## What this skill needs from you

**Required:**

1. **The product or service**, described specifically
2. **The target audience** — and ⭐ **psychographics, not just demographics.** ACA is explicit that
   this is what decides whether the output is any good: *"Mentioning interests, values, and
   lifestyle factors will yield better matches than demographics alone."*
3. **Your current creative approach** — what your messaging and creative actually look like now

**Optional, and it sharpens the output:**

4. What you have already tried and found stale
5. Which markets you sell in, since vertical overlap is geographic
6. Any category you cannot be seen next to

⚠️ **All three required inputs do real work and none is a formality.** Without the current approach,
the output cannot tell you what is *different* from what you already do — which is the entire point.
Ask for it if it is missing.

## ⛔ The failure this skill exists to prevent

**This prompt asks a model to name specific brands in industries it has not researched, and it will
name them, confidently.**

Some will be real brands running exactly the creative described. Some will be real brands that have
never run anything like it. Some will be plausible-sounding names attached to nothing. **All three
arrive in the same format, in the same tone, in one list.**

So the output is never a finding. It is a **hypothesis about where to look.**

| ⛔ Never say | ✅ Say instead |
|---|---|
| "Liquid Death uses shock humour in their ads" | "Liquid Death is worth checking for shock humour — verify in the Meta Ad Library" |
| "These five brands all lead with founder stories" | "Check whether these five lead with founder stories; that is the pattern to test for" |
| "Here are 8 verticals and what they do" | "Here are 8 verticals to research, and what to look for in each" |

**Every brand named is a research target.** Write the output so that survives being skim-read — the
verification step is where the value actually is, and a reader who skips it has a document of
confident fiction.

⚠️ **The verticals are more reliable than the brands.** Reasoning about which industries chase the
same audience is a genuine inference from the audience description. Naming which specific companies
run which specific creative is a claim about the world. Weight your confidence accordingly, and say
so in the output.

## How to run it

1. **Confirm the three required inputs.** Ask for whichever is missing, and push for psychographics
   if the audience is described demographically.
2. **Run the prompt** in `reference/the-prompt.md`, or produce its four outputs directly.
3. **Frame every named brand as a target to verify**, per the rule above.
4. **Deliver the verification plan**, not just the list — `reference/verify-and-use.md` has ACA's
   four-step workflow, which is exactly a verification loop.
5. **End with 2 to 3 test concepts**, which is where ACA's own workflow lands.

## Getting the output right

**Unexpected is the requirement, not a flavour.** The prompt asks for verticals *"that likely target
the same core audience but sell completely different products/services."* If the list comes back
full of adjacent categories — skincare suggesting haircare — it has failed, and the fix is a sharper
audience description rather than a rerun.

**Say what the shared audience actually is.** A vertical is only worth studying if you can name why
its buyers overlap with yours. *"Both sell to time-poor professionals who treat spending as
self-permission"* is a reason. `Both are premium` is not.

**Emotional triggers are the transferable part.** Products do not transfer across verticals; the
trigger being pulled does. That is what makes step 4 of the prompt — techniques to adapt — the
output that matters.

**Do not let it become a competitor audit.** The moment a direct competitor appears in the list, the
prompt has drifted back into the bubble it exists to escape.
