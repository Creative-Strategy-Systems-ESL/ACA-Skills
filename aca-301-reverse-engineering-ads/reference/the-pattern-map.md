# The Pattern Map and the Remix

ACA's artifact for Course 301, shipped as the **Pattern Recognition Playbook** workbook and again as
the graded **Ads Pattern Recognition** assignment. Both carry the same framework.

> "Every ad you admire is built on a pattern someone else proved first. This playbook teaches you to
> see those patterns. Pick three ads ones you genuinely think are great and welll break them apart."

**The selection rule is admiration, not performance.** Zach says *"pick three ads you genuinely
think are great"*. Not the ones that scaled, not the ones with data attached. Taste is the filter,
because the exercise is training the eye.

---

## The six dimensions

Every ad gets read across all six. The option lists are ACA's, given as prompts rather than as a
closed taxonomy.

| Dimension | The question it answers | Options ACA names |
|---|---|---|
| **Hook type** | How does it grab attention in the first 3 seconds? | Pattern interrupt · bold claim · question · controversial take · native/UGC open · visual disruption |
| **Format** | What is the production structure? | Talking head · UGC testimonial · product demo · lifestyle · mashup/montage · founder story |
| **Narrative arc** | What is the story structure? | Problem > agitate > solve · before/after transformation · "I discovered something" story · listicle · myth-busting |
| **Proof mechanism** | How does it build belief? | Social proof · demonstration · authority/credentials · results/data · aspirational identity |
| **CTA style** | How does it close? | Direct offer · curiosity gap · urgency/scarcity · risk reversal · "just try it" |
| **Platform DNA** | What makes it feel native? | Aspect ratio · pacing · sound on/off design · caption style · lo-fi versus polished |

⚠️ **ACA's two documents disagree on the sixth dimension's name.** The Playbook says **Platform DNA**
throughout. The graded assignment's framework table says **Performance DNA**, but its own pattern-map
rows then say **PLATFORM DNA**. This skill uses **Platform DNA**, because two of the three
appearances say it and because the question it asks (*"what makes it feel native?"*) is about the
platform, not about performance. Flagged rather than silently reconciled.

---

## The Pattern Map, one per ad

Header: **Brand · Platform · Ad link.**

Then, for each of the six dimensions, **three fields**:

| Field | What goes in it |
|---|---|
| **THEY DID** | The specific, concrete execution. What is literally on screen |
| **THE PATTERN IS** | The abstraction. The transferable form underneath the execution |
| **SEEN THIS IN** | Where else this pattern appears. Another brand, another category, another era |

⛔ **The gap between the first two fields is the entire exercise.** Getting this wrong is the failure
mode, and it is the common one:

| ❌ Not a pattern (that is THEY DID) | ✅ The pattern |
|---|---|
| "Green screen behind a woman talking" | "Reaction-to-artefact: the creator responds to something on screen rather than addressing camera cold" |
| "Shows the price crossed out" | "Value anchoring against a stated reference price" |
| "Founder in a warehouse" | "Proof by access: showing the part of the business customers never see" |
| "Text says '3 things I wish I knew'" | "Numbered scarcity of insight, promising a finite, completable payoff" |

**The test:** could a brand in a completely different category use this? If not, you have written
down the execution.

⭐ **"SEEN THIS IN" is not decoration, it is the validation step.** A pattern observed once is a
coincidence. The column forces a second sighting, and that is what separates a pattern from a nice
ad. **"Nowhere else yet" is an honest and useful answer** — it means either the pattern is genuinely
novel, which is rare and worth noting, or it has not been abstracted far enough. Check which.

### Filling it well

- **Timestamp the hook** if it is video. "First three seconds" is the definition, so say what happens
  in them rather than describing the ad generally.
- **One dimension can be absent.** An ad with no proof mechanism is a finding, not a gap in the map.
  Write "none" and note it, because a missing dimension is often exactly what makes an ad cheap to
  produce.
- **Do not force an option from the list.** The lists are prompts. If the hook is something ACA does
  not name, name it yourself.

## The Remix

The second half, and the reason the first half exists.

> "Pick one pattern from any ad for each category. Combine."

For each of the six dimensions, two fields:

| Field | What goes in it |
|---|---|
| **MY VERSION** | The pattern, rewritten for this brand, this product, this audience |
| **STEALING FROM AD #** | Which of the three it came from. Kept visible on purpose |

**Then ACA's closing form**, which is the coherence test:

> "A **{FORMAT}** ad that opens with **{HOOK}**, builds belief through **{PROOF}**, and closes with
> **{CTA}**."

⚠️ **The one-sentence form only names four of the six dimensions.** Narrative arc and Platform DNA
are mapped and remixed but do not appear in the summary. That is ACA's template as written. If the
sentence reads well but the ad still feels wrong, the missing two are usually where the problem is,
so check them before rewriting.

### What makes a remix rather than a copy

**Take one dimension from each ad, not all six from one.** Six dimensions from a single ad is that
ad. The design of the exercise, drawing across three sources, is what makes the output new.

**If every dimension came from the same ad, say so and push back.** That is the most likely way this
produces something legally and creatively bad.

**The version must survive translation.** *"You're not stealing the price point. You're stealing the
structure."* If the pattern only works at the source brand's price, category or audience, it did not
transfer, and MY VERSION should say what replaced it.

## Producing it

Deliver as a document with:

1. **A header block** — brand, date, who it is for.
2. **Three pattern maps**, one per ad, each with the six dimensions and their three fields.
3. **The Remix**, six dimensions with MY VERSION and STEALING FROM AD #.
4. **The one-sentence form**, filled.
5. **A "what I could not verify" line.** Anything read from a description rather than from the ad
   itself, any "SEEN THIS IN" recalled rather than checked, marked as such.

⛔ **Mark inferences inside the document, not only in the covering message.** A pattern map gets
pasted into a deck, forwarded, and read a month later by someone who never saw the conversation. If
a "SEEN THIS IN" is from memory rather than from a checked example, it has to say so **in the cell**,
because that is the only place it will still be visible when it matters. Use `⚠️ from memory, not
verified`.

⚠️ **If the ads were described rather than supplied, say so at the top.** A pattern map built from
someone's description of an ad is a map of the description. Useful, but not the same artifact, and
the difference should be visible to whoever reads it next.

### ACA's own submission requirement

The assignment version is graded:

> "Export this document as a single PDF and submit it via the submission screen so your work can be
> marked."

Worth mentioning to anyone working through the certification, because the deliverable format is
specified and a filled map in some other form will not submit.
